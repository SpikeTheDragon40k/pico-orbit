# Changelog

## 0.1.0 — implementation candidate

- Audited the original game at commit 67acff0600263f813122d6993b51897fe687d77e.
- Added standalone cartridge assembly and PICO-specific validation.
- Added single-player elimination matches with 1–3 predictive CPUs, four arenas/difficulties, round progression and setup.
- Added DASH, offset-and-motion GRAB/THROW, spin/Magnus, ramping, shields, personal slow motion, multiball and wide paddles.
- Added cosmetic pilots, original primitive art, trails, sequenced music/effects, pause settings and profiling overlay.
- Added deterministic desktop regression/tournament execution of source and assembled cartridge.
- Official runtime, graphical/audio/controller and performance verification remain open; this is not a certified final release.
